B) OneDrive business

1. Creează aplicația Microsoft in Entra ID
Intră în Microsoft Entra admin center → App registrations → New registration.
La Supported account types, alege opțiunea care include:
Accounts in any organizational directory and personal Microsoft accounts

După creare, copiază:
- Application (client) ID → ONEDRIVE_CLIENT_ID
- pentru OneDrive personal vei folosi consumers ca tenant → ONEDRIVE_TENANT_ID=consumers
Microsoft folosește explicit endpointul consumers pentru autentificarea conturilor Microsoft personale. Microsoft Learn

2. Configurează Redirect URI
În:
App registrations → aplicația ta → Authentication → Add a platform → Web
poți pune, de exemplu:
http://localhost:3000/callback
Trebuie să folosești exact aceeași adresă când obții authorization code-ul.

3. Creează Client Secret
Mergi la:
Certificates & secrets → Client secrets → New client secret
Copiază imediat valoarea din coloana Value.
Aceasta devine:
ONEDRIVE_CLIENT_SECRET

Secretul este necesar atunci când aplicația web schimbă authorization code-ul cu tokenurile OAuth. Microsoft Learn

4. Adaugă permisiunile Graph

API permissions → Add a permission → Microsoft Graph → Delegated permissions

Files.ReadWrite
User.Read
offline_access

Files.ReadWrite permite aplicației să citească, creeze, modifice și șteargă fișierele utilizatorului autentificat. Pentru conturile Microsoft personale poate accesa și fișierele partajate cu acel utilizator. Microsoft Learn
